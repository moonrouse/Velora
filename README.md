# Velora Store

React + Vite frontend store template in JavaScript.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Структура

- `src/components` — UI-компоненты
- `src/pages` — страницы
- `src/redux` — состояние приложения
- `src/locales` — переводы на русском и английском
- `src/styles` — глобальные стили
